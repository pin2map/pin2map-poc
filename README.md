**Webseite / iPhone-Test:** https://pin2map.github.io/pin2map-poc/

Dies ist die **öffentliche Bedienoberflächen-Vorschau** von pin2map NEW, aufgebaut auf einer zunächst identischen Kopie der Vorgängerversion. Änderungen erfolgen schrittweise im PoC. Der Originalcode ist in `index.html` erweitert; dies ist noch **nicht** die endgültige NEW-Architektur.

**Wichtig für neue Chats und Mitwirkende:** Die verbindliche Projektplanung, der dokumentierte aktuelle Stand und die Gründe für UI-Änderungen stehen im **separaten privaten** Repository `pin2map/pin2map-2`, insbesondere `docs/POC_HANDOFF.md` und `docs/PROJECT_STATE.md`. Der Assistent sollte die Dokumente bei einer Änderungsanforderung **selbständig lesen**; der Nutzer muss keine besondere Übergabeanweisung formulieren. Siehe `AGENTS.md`.

**Nach jeder Änderung**: Hier `index.html` committen und Deployment kontrollieren; **ohne Nachfrage** zugleich die Übergabedokumentation in `pin2map/pin2map-2/docs/POC_HANDOFF.md` aktualisieren. Die GitHub-Historie ist automatisch; das erläuternde Übergabedokument erfordert einen eigenen Commit.

Die ursprüngliche Anwendung `pin2map/pin2map` bleibt unberührt. Keine Fotos geplant, keine produktive Synchronisierung im PoC.
